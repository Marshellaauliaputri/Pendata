Analisa Data Kesuburan Tanah#

1. Analisis Data menggunakan K-Nearest Neighbors (KNN)#

Analisis ini bertujuan untuk mengklasifikasikan tanah menjadi dua kelas, yaitu Subur dan Tidak Subur, menggunakan algoritma K-Nearest Neighbors (KNN).

2. Pemrosesan Data#

Data diproses melalui beberapa tahap menggunakan widget di Orange, yaitu:

a. File#

Widget File digunakan untuk mengimpor atau memasukkan dataset ke dalam Orange sebagai tahap awal analisis data. data yg ku pakai menggunakan format .xlsx

b. Impute#

Pada dataset kesuburan tanah terdapat beberapa nilai yang kosong. Jika tidak ditangani, data tersebut dapat menyebabkan error atau menurunkan performa model.

Oleh karena itu digunakan metode imputasi:

  • Data numerik (seperti pH tanah, nitrogen, dll) : diisi dengan rata-rata (mean)

  • Kategorikal data (seperti tekstur tanah) : diisi dengan nilai yang paling sering muncul (modus)

c. Select Columns#

Fitur dipilih karena berpengaruh terhadap kesuburan tanah, sedangkan target yang ditentukan agar model dapat melakukan klasifikasi dengan tepat.

d. Continuize#

Widget Continuize digunakan untuk mengubah kategori data menjadi bentuk numerik agar dapat diproses oleh algoritma seperti KNN. Data seperti tekstur tanah yang awalnya berupa kategori (misalnya: liat, pasir) akan diubah menjadi angka dalam bentuk kolom baru.

e. Preprocess#

Menormalkan data numerik agar semua fitur berada dalam rentang yang sama, yaitu dari 0 sampai 1. Dengan begitu, nilai dari setiap atribut seperti pH, nitrogen, dan lainnya menjadi sebanding.

Pengaturan:

  • Pilih Normalisasi ke interval [0, 1]

f. kNN KNN (K-Nearest Neighbors)#

KNN dengan k=5, Euclidean, dan Uniform digunakan untuk klasifikasi berdasarkan jarak, agar hasil stabil dan cocok untuk data numerik.

g. Test and Score#

Test & Score digunakan untuk melihat hasil performa model KNN melalui metrik seperti akurasi, presisi, recall, dan F1-score.

3. Hasil perhitungan metrik evaluasi#

Hasil pada widget Test & Score menunjukkan kinerja akhir dari model KNN dalam mengklasifikasikan data kesuburan tanah. Dari hasil tersebut, terlihat bahwa semua nilai metrik seperti Accuracy, Precision, Recall, dan F1-Score bernilai 1.000 .
