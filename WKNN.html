Weighted K-Nearest Neighbor (WKNN)#

Dalam metode Weighted K-Nearest Neighbor (WKNN), Yang dimaksud tetangga adalah data lain dalam dataset yang memiliki nilai paling mirip atau paling dekat dengan data yang sedang dianalisis.

Metode WKNN bekerja dengan mencari beberapa data yang paling mirip dengan suatu data tertentu. Data-data yang paling mirip tersebut disebut tetangga terdekat (nearest neighbors). Nilai dari tetangga ini kemudian digunakan untuk membantu memperkirakan nilai yang belum diketahui.

Misalnya terdapat sebuah dataset yang berisi informasi umur dan tinggi badan. Jika ada satu data yang nilai tingginya hilang, maka algoritma WKNN akan mencari data lain yang memiliki umur paling mendekati. Data yang memiliki nilai paling dekat tersebut dianggap sebagai tetangga dan digunakan sebagai acuan untuk memperkirakan nilai yang hilang.

Berikut adalah Data di excel:

A. DataSet#

Dataset berikut menunjukkan hubungan antara tinggi badan dengan berat badan.

Data target:

  • Tinggi badan = 165 cm

  • Berat badan = ? (hilang)

Tujuan dari perhitungan ini adalah memperkirakan nilai berat badan yang hilang dengan metode Weighted K-Nearest Neighbor (WKNN).

B. Menghitung Jarak#

Langkah pertama adalah menghitung jarak antara data target dengan setiap data pada dataset menggunakan Euclidean Distance.

Rumus Euclidean Distance:

\[ d(x,y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2} \]

Karena pada contoh ini hanya terdapat 1 atribut (tinggi badan), maka rumusnya menjadi:

\[ d = \sqrt{(X_i - X_{target})^2} \]

dengan:

\(X_i\) = tinggi badan setiap data

\(X_{target}\) = tinggi badan target

\[ X_{target} = 165 \]

Hasil Perhitungan Jarak:

Nilai selisih diperoleh dari:

\[ X_i - X_{target} \]

Sedangkan kuadrat jarak diperoleh dari:

\[ (X_i - X_{target})^2 \]

C. Menghitung Kemiripan#

Setelah jarak dihitung, langkah berikutnya adalah menghitung bobot atau kemiripan. Pada metode ini, bobot ditentukan dengan menggunakan kebalikan dari jarak.

Rumus yang digunakan adalah:

\( w = \frac{1}{d} \)

dengan:

  • 𝑤 = bobot / kemiripan

  • 𝑑 = jarak antara data dan data target

Hasil perhitungan bobot:

Semakin kecil jarak suatu data terhadap data target, maka bobotnya akan semakin besar. Dengan demikian, data yang lebih dekat akan memberikan pengaruh yang lebih besar terhadap hasil prediksi.

D. Weighted Average#

Pada tahap ini setiap bobot dikalikan dengan nilai output (berat badan) untuk mendapatkan nilai weighted value. Tujuannya agar data yang lebih dekat memiliki pengaruh yang lebih besar terhadap hasil estimasi.

Rumus weighted value:

\[ w_i \times Y_i \]

dengan:

  • \(𝑤_𝑖\) = bobot data ke-i

  • \(𝑌_𝑖\) = berat badan data ke-i

Hasil perhitungannya adalah sebagai berikut:

Jumlah bobot:

\[ 0.066666667 + 0.1 + 0.2 + 0.2 + 0.1 + 0.066666667 = 0.733333334 \]

Jumlah bobot x berat badan:

\[ 3 + 5 + 11 + 13 + 7 + 5 = 44 \]

E. Hasil Estimasi#

Nilai estimasi diperoleh dengan membagi jumlah bobot x berat badan dengan jumlah bobot.

Rumus estimasi:

\[ Y = \frac{\sum (w_i \times Y_i)}{\sum w_i} \]

Substitusi nilai:

\[ Y = \frac{44}{0.733333334} \]
\[ Y = 60 \]

Jadi, hasil estimasi berat badan untuk seseorang dengan tinggi badan 165 cm adalah: 60

F. CODE PERHITUNGAN#

import math

# DATASET
tb = [150, 155, 160, 170, 175, 180]
bb = [45, 50, 55, 65, 70, 75]

target = 165

print("DATASET")
print("Tinggi Badan :", tb)
print("Berat Badan  :", bb)
print("Target TB    :", target)
print()

# 1. Selisih
selisih = []
for t in tb:
    s = t - target
    selisih.append(s)

print("SELISIH :", selisih)

# 2. Kuadrat
kuadrat = []
for s in selisih:
    k = s**2
    kuadrat.append(k)

print("KUADRAT :", kuadrat)


# 3. Bobot (w = 1/d)
bobot = []
for d in jarak:
    w = 1/d
    bobot.append(w)

print("BOBOT :", bobot)

# 4. Bobot x Berat Badan
bobot_bb = []
for i in range(len(bb)):
    hasil = bobot[i] * bb[i]
    bobot_bb.append(hasil)

print("BOBOT x BB :", bobot_bb)

# 5. Total bobot
total_bobot = 0
for b in bobot:
    total_bobot += b

print("TOTAL BOBOT =", total_bobot)

# 6. Total bobot x berat badan
total_bobot_bb = 0
for x in bobot_bb:
    total_bobot_bb += x

print("TOTAL BOBOT x BB =", total_bobot_bb)

# 7. Estimasi
estimasi = total_bobot_bb / total_bobot

print("HASIL ESTIMASI BERAT BADAN =", estimasi)

Normalisasi Data#

Normalisasi data adalah proses mengubah nilai data ke dalam skala yang sama agar perbedaan rentang nilai antar fitur tidak mempengaruhi hasil analisis. Dalam data mining dan machine learning, normalisasi penting karena banyak algoritma seperti KNN, WKNN, dan clustering menggunakan perhitungan jarak.

Jika suatu fitur memiliki nilai jauh lebih besar daripada fitur lain, maka fitur tersebut dapat mendominasi perhitungan. Oleh karena itu, normalisasi digunakan untuk membuat data lebih seimbang dan mudah dibandingkan.

Tujuan Normalisasi Data:

  • Beberapa tujuan utama normalisasi data antara lain:

  • Menyamakan skala data antar variabel.

  • Menghindari dominasi fitur tertentu yang memiliki nilai lebih besar.

  • Mempermudah proses analisis data dalam algoritma machine learning.

  • Meningkatkan akurasi model terutama pada metode berbasis jarak.

  • Membantu proses konvergensi pada beberapa algoritma pembelajaran mesin.

Contoh Dataset:

1. Min-Max Normalization#

Min-Max Normalization mengubah data ke rentang 0 sampai 1. Nilai terkecil menjadi 0, nilai terbesar menjadi 1, dan nilai lainnya berada di antaranya.

Rumus:

\[ x' = \frac{x - x_{min}}{x_{max} - x_{min}} \]

Keterangan:

  • \(x\) = nilai data

  • \(x_{min}\) = nilai minimum dalam dataset

  • \(x_{max}\) = nilai maksimum dalam dataset

  • \(x'\) = hasil normalisasi

Perhitungan Tinggi Badan

Dari tabel:

  • MIN = 150

  • MAX = 180

Contoh untuk 150:

\[ x' = \frac{150 - 150}{180 - 150} \]
\[ x' = 0.1667 \]

Contoh untuk 170:

\[ x' = \frac{170 - 150}{180 - 150} \]
\[ x' = \frac{20}{30} \]
\[ x' = 0.6667 \]

2. Z-Score Normalization#

mengubah data berdasarkan rata-rata dan standar deviasi. Hasilnya menunjukkan seberapa jauh suatu nilai dari rata-rata.

Rumus:

\[ x' = \frac{x - \mu}{\sigma} \]

Keterangan:

  • \(x\) = nilai data

  • \(\mu\) = rata-rata (mean)

  • \(\sigma\) = standar deviasi

  • \(x'\) = hasil normalisasi

Perhitungan Tinggi Badan

Dari tabel:

  • AVG = 165

  • STDEV = 10.801234

Contoh untuk 150:

\[ x' = \frac{150 - 165}{10.801234} \]
\[ x' = \frac{-15}{10.801234} \]
\[ x' = -1.3887 \]

Contoh untuk 170:

\[ x' = \frac{170 - 165}{10.801234} \]
\[ x' = \frac{10}{10.801234} \]
\[ x' = 0.9258 \]

3.Decimal Scaling#

Metode normalisasi dengan cara membagi data dengan pangkat 10 sampai nilainya menjadi lebih kecil.

Rumus:

\[ x' = \frac{x}{10^j} \]

Keterangan:

  • \(x\) = nilai data

  • \(j\) = jumlah digit dari nilai terbesar pada dataset

  • \(x'\) = hasil normalisasi

Perhitungan

Untuk tinggi badan, nilai terbesar adalah 180, jadi dibagi 1000.

Contoh:

\[ x' = \frac{150}{1000} \]
\[ x' = 0.15 \]

Untuk berat badan, nilai terbesar adalah 75, jadi dibagi 100.

Contoh:

\[ x' = \frac{45}{1000} \]
\[ x' = 0.45 \]

CODE PERHITUNGAN#

import pandas as pd
from sklearn.preprocessing import MinMaxScaler, StandardScaler

# Dataset
data = {
    "Tinggi_Badan": [150, 155, 160, 170, 175, 180],
    "Berat_Badan": [45, 50, 55, 65, 70, 75]
}

df = pd.DataFrame(data)

print("DATASET")
print(df)
print()

# =========================
# 1. MIN-MAX NORMALIZATION
# =========================
minmax_scaler = MinMaxScaler()
minmax_result = pd.DataFrame(
    minmax_scaler.fit_transform(df),
    columns=["TB_MinMax", "BB_MinMax"]
)

print("MIN-MAX NORMALIZATION")
print(minmax_result)
print()

# =========================
# 2. Z-SCORE NORMALIZATION
# =========================
zscore_scaler = StandardScaler()
zscore_result = pd.DataFrame(
    zscore_scaler.fit_transform(df),
    columns=["TB_ZScore", "BB_ZScore"]
)

print("Z-SCORE NORMALIZATION")
print(zscore_result)
print()

# =========================
# 3. DECIMAL SCALING
# =========================
decimal_result = pd.DataFrame()
decimal_result["TB_Decimal"] = df["Tinggi_Badan"] / 1000
decimal_result["BB_Decimal"] = df["Berat_Badan"] / 100

print("DECIMAL SCALING")
print(decimal_result)
print()

# =========================
# GABUNG SEMUA HASIL
# =========================
hasil = pd.concat([df, minmax_result, zscore_result, decimal_result], axis=1)

print("HASIL LENGKAP NORMALISASI")
print(hasil)
